# Hava81 Support

For reproducible bugs, use the repository's **Bug report** issue form. For product ideas, use **Feature request**.

Before opening a new issue:

1. Check existing open and closed issues for the same problem.
2. Confirm the problem still occurs on the current production app.
3. Include the city, browser/device, steps to reproduce and screenshots when relevant.

For API problems, include the endpoint and response status but never include API keys, tokens or other secrets.

Security-sensitive reports must follow [SECURITY.md](SECURITY.md) instead of a public issue.
